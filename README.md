## **DOWNLOAD:**

* Click the green "Code" button top right
* select the lowest option called "Download Zip"
* extract


## **FIRST TIME JOINING THE SERVER?**

minecraft java 1.18.2  -  install via official Minecraft Launcher (you can also use the prism launcher which is a bit faster and less prone to issues: https://prismlauncher.org/

forge install - forge-1.18.2-40.0.52-installer.jar in the downloaded zip



## **ADDING OR UPDATING THE MODS:**

hit Win+R keys, type "%APPDATA%" (without quotes) - this brings you to AppData/Roaming/

copy the .minecraft folder in this archive to "C:\Users\yourUsername\AppData\Roaming"


## **JOINING**

in minecraft, add a server with the current IP

You will find the current IP in the "minecraft-server" text channel on Maxims Discord server

If it doesn't work, send me a message. Maybe the server is not running yet, or the IP has changed recently.
